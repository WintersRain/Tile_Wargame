# Tile Wargame

**STATUS: Early Development - Not Playable**

A turn-based strategy wargame with deep tile-based territorial control.

## Features (Planned)

- 8-directional tile sections with distinct terrain
- WeGo simultaneous turn resolution
- Scout and intel systems
- Building chains and resource management

## Tech Stack

| Layer | Tech |
|-------|------|
| Shell | Tauri |
| Simulation | Rust |
| Graphics | PixiJS |
| UI | React + TypeScript |

## Running Locally

Requires: Node.js, Rust, Tauri CLI

```bash
npm install
npm run tauri dev
```

## Current State

This project is in early development. The foundational code structure is in place, but the core gameplay loop hasn't been implemented yet. If you're looking for something playable, check back later.
